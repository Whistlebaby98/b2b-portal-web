# NOVA 商采云

面向企业客户的对公商城前端工作台，基于 **TypeScript + Next.js + React + Tailwind CSS** 构建。

## 已落地的工作台体验

- 企业主 / 子账号语境与企业认证状态展示
- 待我审批订单、金额阈值提醒和审批中心入口
- 企业协议价、阶梯价、可售库存与交期信息
- SKU / OEM 搜索入口和批量采购清单识别
- 授信额度、账期结算、对公发票与电子合同快捷入口
- 采购车数量调整、加购、批量加购和操作反馈 Toast

## 本地运行

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 查看工作台。

生产构建：

```bash
npm run build
npm run start
```
